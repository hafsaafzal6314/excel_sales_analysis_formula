# Excel Sales Analysis Using Formulas

## Project Overview

This project demonstrates data analysis in Microsoft Excel using a retail sales dataset containing 50 orders. The analysis focuses on extracting business insights using Excel formulas rather than Pivot Tables or Power BI.

## Dataset Columns

* Order ID
* Order Date
* Region
* Category
* Product
* Sales
* Quantity

## Excel Functions Used

### SUMIF

Used to calculate:

* Total sales by region
* Total sales by category

### COUNTIF

Used to calculate:

* Number of orders from each region

### SUMIFS

Used to calculate:

* Total sales for multiple conditions
* Example: Sales from North region and Electronics category

## Business Questions Answered

1. What are the total sales for each region?
2. How many orders came from each region?
3. What are the total sales for each product category?
4. What are the sales from North region for specific categories?
5. Which region generated the highest revenue?

## Key Insights

* East region generated the highest sales revenue.
* Electronics was the highest-selling category.
* Regional sales distribution was relatively balanced across all regions.
* SUMIFS enabled multi-condition analysis for deeper business insights.
